# Contributing

Thanks for your interest in contributing to Jira Subtask Monitor.

## Ground Rules
- Be respectful and constructive.
- Keep changes focused and explain the why.
- Do not include secrets or personal data in issues, PRs, or commits.

## Development Setup
```bash
pnpm install
pnpm run dev
```

## Tests
```bash
pnpm test
```

## Coding Style
- Use TypeScript with explicit types for public functions.
- Prefer small, testable helpers.
- Keep UI changes consistent with `DESIGN_SYSTEM.md`.

## Commit & PR Guidelines
- Keep PRs small and focused.
- Add tests when changing behavior.
- Update docs if you change configuration or APIs.

## Security
If you discover a security issue, please do not open a public issue.
Open a private report or email the maintainer.
